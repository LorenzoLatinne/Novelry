# Novelry
## Beschrijving
Novelry is een moderne leesapp waarmee je niet alleen boeken kunt bijhouden, maar ook persoonlijke leesdoelen kunt instellen en je leesgewoonten kunt visualiseren. 
In plaats van een druk sociaal platform focust Novelry op jouw individuele leeservaring. 
Je ontdekt boeken op basis van jouw tempo en voorkeuren. Zo wordt lezen weer persoonlijk, overzichtelijk en motiverend.

## Features
- Houd eenvoudig bij wat je gelezen hebt, aan het lezen bent of nog wilt lezen.
- Krijg boekentips afgestemd op jouw genres, leesgedrag en favorieten.
- Geen sociale druk of overvolle feeds; de focus ligt volledig op jouw leeservaring.
- Voeg eigen reviews toe aan elk boek om je leesreis vast te leggen.
- Gebruik een timer om een overzicht te krijgen van hoeveel je leest.
